\# 🚗 Turbo Dodge



Turbo Dodge is a 2D car-dodging game built using Python and Pygame.



The player controls a car, avoids obstacles, collects coins, uses power-ups, and activates nitro to survive and achieve a high score.



\## 🎮 Features



\- 🚗 Player car movement

\- 🚧 Multiple types of obstacles

\- 🪙 Coin collection system

\- ⚡ Nitro boost

\- 🛡️ Shield power-up

\- 🐌 Slow-motion power-up

\- ❤️ Extra-life power-up

\- 📈 Increasing difficulty and levels

\- 🏆 High-score system

\- 🔊 Synthesized sound effects

\- ⏸️ Pause system

\- 🔇 Mute/unmute option

\- 🎨 Procedurally generated graphics

\- 🖼️ Optional custom images



\## ⌨️ Controls



| Key | Action |

|---|---|

| ← / A | Move left |

| → / D | Move right |

| SPACE / SHIFT | Nitro boost |

| P / ESC | Pause |

| M | Mute / Unmute |

| R | Restart after game over |

| Q | Quit / Return to menu |



\## 🛠️ Requirements



\- Python 3.12 or compatible Python version

\- Pygame 2.6.1
